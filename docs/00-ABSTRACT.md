# Heliosonic Sonifier — Project Abstract

## Abstract

The **Heliosonic Sonifier** is a real-time artistic sonification instrument that
transforms NOAA/SWPC space-weather data — solar wind, sunspot activity, and
coronal mass ejections — into adaptive MIDI music. Rather than mapping data to
sound one-to-one (*representation*), the system employs a **1:N transduction
paradigm** (*resonance*), in which a single data-event radiates across harmonic,
rhythmic, textural, spatial, and affective layers, reorganizing the internal
state of a computational organism.

The instrument integrates three AI systems — a **state-aware 3rd-order Markov
melody generator**, an **episodic reinforcement-learning memory** with dynamic
learning rate, and a **quantum-inspired glitch engine** — coordinated by an
adaptive 8-state manager operating at 20 Hz. Physical concepts (helioseismic
p-/g-modes, black-hole dynamics, quantum mechanics) are used as **generative
constraints and artistic metaphors**, with explicit scientific transparency
distinguishing verified, theoretical, and artistic references.

## Connection to *AI as Catalyst*

Developed within *AI as Catalyst: Transformative Impacts on Digital Performance,
Computational Music, and Cultural Creativity* (FCT 2024.09158.CEECIND,
2026–2029), the Heliosonic Sonifier embodies the project's thesis that **AI is
a catalyst for — not a substitute of — human creativity**:

1. **Digital Performance:** The system is a live performance instrument in which
   a human performer (via joystick and hardware controllers) co-creates with
   autonomous AI agents in real time.
2. **Computational Music:** Its generative core (Markov chains, genetic
   algorithms, reinforcement learning) advances AI-driven compositional practice.
3. **Cultural Creativity:** By framing scientific metaphors as compositional
   material, it expands the cultural vocabulary of data-driven art.

The system is grounded in the **AI-Chimera** ontogenetic framework
(X = {B, M, A, E, Be}), defining intelligence operationally as *differential
sensitivity to the environment* (I = ∂Be/A), and in the **SRT7** diagnostic
framework (AVANCA 2026) and **Post-Techno aesthetics** (EIMAD 2026).
