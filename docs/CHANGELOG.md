# Changelog

All notable changes to the **Heliosonic Sonifier** documentation are recorded
here. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/).

> **Note:** This repository is documentation-only. Version numbers track the
> instrument build described by the documentation, not distributed binaries.

## [18.5.0] — 2026-08-08

### Added
- Full documentation suite (eight docs) covering overview, architecture,
  AI systems, MIDI output, hardware, data mapping, performance, and
  scientific transparency.
- `CITATION.cff` for GitHub-native citation metadata.
- `CONTRIBUTING.md` with documentation-only contribution guidelines.
- Journal entries #10 (architecture) and #11 (scientific transparency).
- Helioseismic modulation documentation (p-modes 3 mHz, g-modes theoretical).
- Performance metrics and mapping-accuracy tables (97.0% overall accuracy).
- Chandrasekhar-limit rhythm collapse and cosmological inertia metaphors.

### Documented
- 7-layer real-time pipeline operating at 20 Hz (50 ms frame budget).
- 25-module inventory (~18,450 LOC) and 20 autonomous AI agents.
- 16-channel MIDI architecture with visible (CH 15) and internal (CH 16) CCs.
- Custom hardware: 16-key, 12-key controllers, and T.Flight Stick X joystick.
- NOAA/SWPC → music mapping with 1:N transduction paradigm.

### Changed
- Clarified that quantum and black-hole models are computational metaphors,
  not scientific simulations.
- Distinguished VERIFIED, THEORETICAL, and ARTISTIC physical references.

## [18.4.0] — 2026-06-22

### Added
- MusicalMapper advanced expressive layer (CCs on internal channel).
- AdaptiveMemory V3.4 dynamic learning rate (2–60%).
- Performance Controls module (build-up, drop, glitch burst, solar flare, etc.).

## [16.1.0] — 2026-06-01

### Added
- AdaptiveStateManager V7.0 with crossfade, ADSR envelopes, and prediction.
- NOAA panel with real-time data display.
